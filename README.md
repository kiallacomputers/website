# Kialla Computers Main Website

Nuxt 4 rebuild of www.kiallacomputers.com.au, designed to match the Kialla Computers online shop branding.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is configured for Netlify through the Nuxt Nitro Netlify preset.
